STEP 1

Cloudflare + R2 — the media bucket

free ≤ 10 GB, then $0.015/GB-mo

Holds the 10 GB of audio and 568 covers. R2 over S3/Bunny because egress is unmetered — people streaming music all day costs transfer, not money. You're at ~10.03 GB, so expect about $0.05/month. R2 asks for a card even on the free plan.

Keep the three values handy — they become env vars in step 4: R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, plus R2_BUCKET=lifestream and the public base from above.
STEP 2

Upload the library to R2

one-time, ~10 GB from home

A bulk copy from your Mac's .storage directory into the bucket. rclone speaks R2 natively and can resume if interrupted — at a typical 20 Mbps up, budget a few hours; it runs happily overnight.

rclone config create r2 s3 \ provider=Cloudflare \ access_key_id=YOUR_ACCESS_KEY_ID \ secret_access_key=YOUR_SECRET_ACCESS_KEY \ endpoint=https://YOUR_ACCOUNT_ID.r2.cloudflarestorage.com
rclone copy .storage/a r2:lifestream/a --transfers 8 -P \ --header-upload "Cache-Control: public, max-age=31536000, immutable" rclone copy .storage/img r2:lifestream/img --transfers 8 -P \ --header-upload "Cache-Control: public, max-age=31536000, immutable"
STEP 3

Neon — the Postgres database

free tier, plenty

All the metadata (users, tracks, albums, plays, playlists) is a few MB — Neon's free 0.5 GB is ample, and it pauses when idle so it costs nothing for a quiet site.

pg_dump --no-owner --no-privileges lifestream > lifestream.sql psql "NEON_DIRECT_CONNECTION_STRING" -v ON_ERROR_STOP=1 -f lifestream.sql
Starting empty instead (fresh site, no accounts or play history): run DATABASE_URL="NEON_POOLED…" npm run db:push — then register yourself on the live site as the first user.

STEP 5

Custom domain — optional but recommended

~$10/yr for the domain

Two wins: a real name instead of *.vercel.app, and a proper domain for R2 media. The free pub-xxxx.r2.dev URL is meant for testing — Cloudflare rate-limits it, and some networks are slow on it. A subdomain like media.yourdomain.com served by R2 is production-grade and still free.

Monthly cost$0 – $0.10 (R2 storage past 10 GB; everything else free at this scale)
Deploying changesgit push — Vercel builds and swaps automatically; a bad build never goes live
Importing more music laterRun the import scripts locally with DATABASE_URL = Neon pooled string and STORAGE_MODE=r2 + the R2 vars — they write straight to production, same as they did locally
BackupsNeon: dashboard → Restore keeps PITR history; R2: enable bucket → Settings → Object Versioning if you want delete protection; the source of truth is still your Mac
Watching itVercel dashboard → Logs for the app; Neon → Monitoring; R2 → Metrics for storage and requests
